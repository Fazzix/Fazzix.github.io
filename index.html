Original Artifact: Inventory Tracker (CS 360)

A Java Android app built in CS 360: Mobile Architecture and Programming (September 2026). Users register and log in, manage inventory items in a grid backed by SQLite, and can enable SMS alerts when an item runs out of stock.

  • DatabaseHelper.java — SQLite tables and queries
  • InventoryActivity.java — inventory screen and low-stock alerts
  • MainActivity.java — login
  • RegisterActivity.java — account creation
  • SmsPermissionActivity.java — SMS permission
  • InventoryAdapter.java — grid adapter
